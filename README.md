# KESRA Jabar Web

## Project Overview

KESRA Jabar Web adalah aplikasi web yang dikembangkan untuk mendukung penyajian informasi dan pengelolaan konten pada lingkungan KESRA Jabar.

Aplikasi ini menyediakan halaman informasi publik, pengelolaan dokumen, artikel, serta dashboard untuk membantu pengelolaan konten secara terstruktur.

Project ini dikembangkan sebagai bagian dari kegiatan **internship di Sekretariat Daerah Provinsi Jawa Barat (Sekda Jabar)**.

## Project Purpose

Project ini bertujuan untuk mengembangkan aplikasi web yang dapat digunakan untuk:

- Menyediakan informasi mengenai KESRA Jabar.
- Menampilkan dokumen dan arsip secara terstruktur.
- Menampilkan informasi dan artikel kegiatan.
- Mengelola artikel melalui dashboard.
- Menyediakan antarmuka yang responsif dan mudah digunakan.
- Mengintegrasikan aplikasi dengan database menggunakan Supabase.

## Main Features

### Beranda

Menampilkan informasi utama dan konten mengenai KESRA Jabar.

### Arsip Dokumen

Menyediakan halaman untuk menampilkan dan mengelola dokumen berdasarkan kategori dan informasi yang tersedia.

### Artikel

Pengguna dapat melihat daftar artikel dan membuka halaman detail artikel.

### Article Management

Dashboard menyediakan fitur pengelolaan artikel, meliputi:

- Menampilkan daftar artikel
- Menambahkan artikel
- Mengedit artikel
- Melihat detail artikel

### Dashboard

Dashboard digunakan sebagai area pengelolaan konten aplikasi.

### Responsive Interface

Antarmuka aplikasi dirancang agar dapat digunakan pada berbagai ukuran layar.

## Installation

Clone repository:

    git clone https://github.com/USERNAME/kesra-jabar-web.git

Masuk ke folder project:

    cd kesra-jabar-web

Install dependencies:

    npm install

Jalankan development server:

    npm run dev

Build project:

    npm run build

Preview production build:

    npm run preview

## Environment Variables

Project menggunakan Supabase untuk kebutuhan database dan layanan terkait.

Buat file `.env` pada folder utama project:

    VITE_SUPABASE_URL=your_supabase_url
    VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

Jangan mengunggah file `.env` yang berisi credential asli ke GitHub.
